Some stations have optional entries for more than one input flow stream,
for example, melters, tanks, receivers, and separators/filters. Data
that controls the performance of each station is entered using the
respective station properties windows in Sugars.

 

Building a new model is simply a matter of dragging shapes from the
Sugars stencils to the drawing surface, connecting the shapes with the
Visio connector tool to reflect the process flows in the factory,
connecting flows that leave the model to output ports on the appropriate
stations, and adding all external flows that go into the model from
outside sources.

 

The shapes in the Sugars stencils represent stations that are available
in Sugars for building a model of the process. New shapes can be
designed and named to have the same properties as any of the station
modules available in Sugars (see [Designing Your Own
Shapes](Designing_Your_Own_Shapes.htm))

 

Also, station shapes can be grouped together and dragged from the
stencil as a group. Commonly used arrangements of stations can be made
into a group to speed the building of models. For example, one
evaporator body can be grouped with receivers, distributors, and a flash
tank to represent one complete effect with flashing in a multiple effect
model. Some groups of shapes are supplied with the Sugars stencils, but
other groupings can be created and added to the stencils (see [Grouping
Shapes).](Grouping_Shapes.htm)
