# Compressor Features

 

Compressor A compressor station is used to compress vapor by mechanical
vapor recompression (MVR).

 

<img src="../../assets/images/Compressor/CompressorFeatures_Fig-1.png" style="border: none;"
data-border="0" />

 

General Features Vapor into the compressor will be compressed to give a
pressure and temperature for the vapor flow out that is equal to the
specified values for the station (values entered on the Compressor
Properties window). Both the discharge pressure and temperature must be
specified. Sugars will not allow the discharge temperature to be below
the saturation temperature during the iterations. That is, vapor
condensation is not allowed.
